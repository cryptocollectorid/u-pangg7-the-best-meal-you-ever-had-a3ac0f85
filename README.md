One sentence, at most 200 characters, about the best meal ever had — a
make.fun bounty entry ([bounty page](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85)).

## Entry

> My grandmother's soto ayam in Jakarta — turmeric broth, shredded chicken, a boiled egg at her dawn kitchen table, steam fogging my glasses before the first spoonful.

## Run

```sh
python3 main.py   # writes the entry to /output/entry.txt (165 characters)
```

`main.py` validates the entry against the competition gate (UTF-8 text of
1–200 characters, a single non-blank line, no control characters) and
verifies the file on disk with a round-trip read-back before reporting
success.
